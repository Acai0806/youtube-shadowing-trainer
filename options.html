AI 服务设置

采用 OpenAI 兼容协议，主流服务商均可接入。API Key 仅保存在本机浏览器中，请求只发往你填写的地址。

兼容性说明：任何提供 OpenAI 兼容接口的服务商都可以使用，例如 OpenAI、智谱 GLM、硅基流动、Groq、DeepSeek 等； 模型名以服务商控制台为准。语音识别默认使用 Chrome 内置识别，无需任何配置； 只有把「语音识别来源」切换为「云端接口」并填写模型名后，录音才会发送到你配置的 /audio/transcriptions 接口。

隐私说明：保存时会请求一次对应域名的访问权限（浏览器权限弹窗）。 录音与字幕文本只发往你配置的接口，用于转写与表达生成；插件不上传任何数据到其他服务器， API Key 仅存本地 chrome.storage.local。
